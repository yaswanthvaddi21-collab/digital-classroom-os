## Upgrade notes

- **Export a backup before updating** (Settings → Backup). Before each database upgrade the app also makes its own safety copy (ADR 0006).
- **One-way upgrade.** When 0.2.0 has opened a profile, older builds (0.1.0 and every v0.2 build before Phase 7) can no longer use it. They fail closed: they do not change or delete anything, but they cannot open your work (ADR 0014 §1). To go back, restore a backup in the older build.
- Backups made by 0.2.0 that contain presentations: builds before Phase 7 skip the presentations and say so; 0.1.0 refuses the file (ADR 0014 §3).
- The upgrade from 0.1.0 has been tested in a real browser: 82 of 82 checks passed, in Chromium only (`npm run test:upgrade`, 2026-11-15).

## Known limitations

- **Compatibility with other applications is mostly unverified:**
  - DOCX exports: 2 of 16 files have been checked in Word for Mac.
  - ODT files have never been opened in another application.
  - `.drawio` files have never been opened in diagrams.net.
  - PPTX files have never been opened in PowerPoint, Keynote or LibreOffice.

  Details are in docs/DOCUMENT_COMPATIBILITY.md, docs/DIAGRAM_EXPORTS.md and docs/compatibility/.
- **Firefox** is tested only in GitHub CI; it cannot be launched locally on the development Mac.
- **Missing features:**
  - Documents: no on-screen page view, footnotes, track changes or citations.
  - Diagrams: no multiple pages, concept maps or smart guides.
  - Presentations: no grouping or animation timeline.
  - Notebook, PDF Studio, Classroom Hub, Collaboration, folders and tags are not built yet. The Advanced Edition plan in docs/advanced-edition/ covers them.
- **No accounts, sync or backend in production.** All data stays in each browser. Clearing site data deletes it unless you have a backup.
- **Security:**
  - The web app has no Content Security Policy yet (TD-29, D-23).
  - GitHub's private vulnerability reporting is off (D-39); docs/SECURITY.md gives the reporting route.
- **Desktop (Tauri) and Android (Capacitor) builds** are stubs that have never been built.
- **The deploy is not gated on CI** (D-02). The control is that nothing is pushed to `main` without the owner's approval.
- **The manual acceptance checklist** (tests/acceptance/CHECKLIST.md) was last run on 2026-11-12. It does not yet cover Document, Diagram or Presentation Studio, which rely on the automated suites in docs/TESTING.md.
